# Reference database

**Sources.** First pass: a 826x2000 contact sheet of 169 thumbnails labelled 000-168 (`docs/reference-source-contact-sheet.jpg`). Second pass: `references.zip` was supplied later (169 PNGs, 121-625 px wide: 135 in `inspiration/` and 34 in `inspiration/on screen inspo/`). The sheet was laid out in sorted path order, so tile N is the N-th file of the sorted ZIP listing. This was checked visually on 24 samples spread across the range (`tools/map_zip.py` → `docs/reference-zip-map.json`). The `launch-motion` SKILL.md named in the brief was never supplied.

**These are still images. No animation was observed.** The *Inferred motion* column is a proposal for how a similar design could move. It is not a description of any source video. Two files are named `videoframe_*` (167, 168); they are still frames, and no video was supplied.

- Files: 169 · Unique after duplicate grouping: **127** · Duplicate/variant groups with >1 member: **33** (42 redundant files). Only 016/017 are byte-identical; the other groups are re-exports, re-crops or template variants.
- Method: tiles are cut from the sheet (`tools/extract_references.py`), trimmed, and fingerprinted with SHA-1, dHash and aHash, with the measured palette in `docs/reference-fingerprints.json`. Hash grouping proposed candidates but produced false positives on dark tiles, so the final groups were **confirmed by eye** (`tools/build_reference_db.py`).
- Unreadable files: none. Unavailable: any video and the launch-motion skill.
- The presenter frames (162-166, in `on screen inspo/`) show a real person. They are catalogued for composition only and are not reproduced.
- Second-pass finding from the full-size files: the look that matters is **frosted glass**. That means translucent dark panels, a fine top-edge highlight, and coloured light bleeding through the lower edge of the glass (clearest in the 005/042/075/123 files), set on a deep black backdrop with soft overhead light. The production adopted this look (see `reference-decisions.md`).
